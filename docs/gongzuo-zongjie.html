工作总结怎么写一套结构，五种周期通用

与其到处找范文，不如记住一套结构。下面这套六段式，日报到年报都能套。

Structure

通用六段结构

  1. 结论先行：一两句说清整体结果，达成还是未达成，差距在哪。
  2. 目标对照：把期初目标逐条列出，标明完成度，让读者自己算得分。
  3. 关键动作：每个目标下写 1–3 个你做的具体动作，动词开头。
  4. 数据支撑：能数字化的全部数字化，同比环比都补上。
  5. 问题与改进：只写真实问题，且必须配动作和时间点。
  6. 下一步计划：3 项以内，有目标值、有节点、有责任人。

这六段可以压缩成两段，也可以扩成十段，但顺序不要乱：先结论、再事实、后规划。

Cycle

不同周期的写法差异

日报：只写今天做了什么、明天做什么、卡在哪，200 字以内，不需要反思。

周报：进展 + 结果 + 风险 + 下周计划，重点写风险，领导靠这个提前协调资源。

月报：按月看趋势，必须有环比数据，讲清“这个月比上个月好在哪里”。

季度总结：目标对照为主，讲清阶段成果和资源缺口，为下季度争取支持。

年度总结 / 述职：以岗位价值为主线，讲能力成长和来年规划，不只是把 12 个月拼起来。

Method

五步成稿法

  1. 收集素材：把这一周期的聊天记录、待办、文档变更、数据截图都翻出来，先不筛选。
  2. 归成三类：做成了的、没做成的、过程中的发现。三类各成一组。
  3. 补数字：每组至少有一个可量化指标，没有数字的补上范围或对比。
  4. 排优先级：把影响最大的 3 件事往前放，其余合并成一句带过。
  5. 加首尾：开头写结论，结尾写下一步，中间就是正文。

前两步最花时间，也是最容易被跳过的。把素材直接粘进 智报，这两步可以自动完成，缺数据处会标【待补充】。

Pitfall

四个典型问题

1. 写成流水账。“周一开会、周二写文档”没有信息量，要按事项和目标归并。

2. 全是形容词。“大幅提升”“显著改善”无法验证，换成百分比或绝对值。

3. 只报喜不报忧。没达成的地方藏着不说，评审时一句追问就露。

4. 没有下一步。总结的目的之一是争取资源，不写规划等于放弃这次机会。
