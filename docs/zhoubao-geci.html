周报格式

周报格式结构、排版、字数一次讲清

同一份内容，格式不同，读起来的感受差很多。结构、配比、排版硬规则，这一页说清。

按格式生成周报看周报模板
Layout

标准结构：一行标题、一行周期、四段正文

标题写清「部门 + 姓名 + 周期 + 周报」，例如「产品部 李然｜第 41 周周报（10.8–10.12）」。周期单独占一行，避免和上周的文件混在一起。正文固定四段，顺序不要换：结论摘要、进展与结果、问题与风险、下周计划。领导连看三周就会形成阅读习惯，之后只扫小标题就能抓到重点。

  • 结论摘要：一到两句，回答「这周成了什么」。
  • 进展与结果：按重要性排序，不按时间排序。
  • 问题与风险：影响、措施、需要的支持，三样齐全。
  • 下周计划：三到五条，每条有可交付物和时间。
Ratio

字数配比 1:4:2:3

以一份 700 字的周报为例：结论 70 字以内，进展与结果 280 字左右，问题与风险 140 字，下周计划 210 字。结论超过 100 字，通常说明还没提炼出重点；进展部分占了一半以上，多半是过程细节没删；下周计划不足 150 字，领导会怀疑你对下周没有安排。全篇控制在 600 到 900 字，超过 1000 字，读的人会直接跳到小标题。

Rules

排版五条硬规则

  1. 一段一个结论。每段第一句就是这段的结论，后面才是支撑。
  2. 关键数字加粗。一份周报不超过 8 处，加粗太多等于没加粗。
  3. 标题不超过三级。需要四级标题，说明层级设计有问题，合并成一两句说明。
  4. 不用彩色字和特殊字号。复制到邮件、IM 或文档系统里全部失效，还会显得不专业。
  5. 控制在一页内。A4 一页或屏幕一屏，超出就删，删不掉就挪到附件。
Culture

不同公司的风格差异

国企与事业单位：重规范，标题层级和称谓要完整，小标题多用「完成情况」「存在问题」「下一步举措」，少用口语缩写。

互联网公司：重结论和数据，开门见山，一句话说清结果，过程和会议尽量不写，语气直接。

外企：重结构和可追溯，常用 Summary、Progress、Risks、Next Steps 四段，风险部分要写明应对措施和责任人。

格式只是外壳，先按公司既有文件对齐，再考虑优化。把素材粘进 智报 生成初稿后，按上面的结构删减一遍，比从空白文档开始快得多。
